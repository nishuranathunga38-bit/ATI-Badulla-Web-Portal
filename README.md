# ATI Badulla Web Portal

A web-based portal developed to provide academic information and useful services for students of ATI Badulla.

## Features

- Student-friendly homepage
- Examination notices
- Academic information
- HNDIT, HNDE and HNDA course information
- Live visitor counter
- Admin login
- Easy access to important institute information

## Technologies

- Java
- JSP
- Servlets
- MySQL
- HTML
- CSS
- JavaScript

## Tools

- NetBeans
- XAMPP
- MySQL Workbench
- Apache Tomcat

## Project Purpose

This project was developed as an academic project to provide a simple and user-friendly web portal for accessing academic information and services related to ATI Badulla.
